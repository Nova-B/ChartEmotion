# 노래 차트 대중심리 분석 — 설계 문서

> 한국·일본·미국의 인기 노래에서 어떤 정서와 메시지가 두드러지는지 비교하고, 그 변화의 사회적 의미를 탐구하는 프로그램.
> 출발점: [[2026-09-21 노래 차트로 대중의 심리 분석]] (원 아이디어) ← [[기대의 감각(쉽게 실망하고 체념하는 시대 나를 온전히 믿어주는 힘  전자책 기준)]]
> **이 문서는 사용자 구상에 대한 조사와 LLM의 설계 제안이다.** 아래 MVP 범위·분류 기준·수치 기준은 사용자 확정 사항이 아닌 가안이다. 실제 데이터 수집이나 분석 결과는 아직 없다.
> 2026-09-26 개정: 공식 서비스 문서와 논문을 확인하고, 측정 정의·데이터 확보·검증·산출물을 구체화했다. 확인한 사실에는 출처를 붙이고, 미확인 사항은 그대로 남겼다.

> 개발 진입점: [[00_노래차트_개발기획]]. 요구사항·데이터 계약·개발 작업·파일럿 운영은 연결된 문서에서 관리한다. 이 문서는 연구 배경과 분석 원칙을 담당한다.

## 🪞 Nova의 자리

> 이 칸은 사용자가 직접 쓴다. 설계를 읽고, **무엇이 걸렸는지 / 왜 이걸 만들고 싶은지**를 자기 언어로 남기면 그게 이 프로젝트의 기준선이 된다.

사용자 작성 대기. 이 항목을 대신 채우지 않는다.

원 아이디어에 적힌 목표: “코드로 한국 일본 미국 등의 인기 노래 차트를 분석하여 대중의 심리를 분석할 수 있는 프로그램 만들기.”

**LLM의 발전 제안:** 첫 결과물은 한국 차트 표본의 ‘주제·감정·메시지 변화 보고서’로 만들고, 같은 방법이 일관되게 작동하면 국가 비교와 반복 실행으로 확장한다. 가칭은 **차트 정서 관측소**. 핵심 가치는 정서 점수 하나보다, 변화에 기여한 곡과 반례를 함께 확인할 수 있다는 데 둔다.

## 1. 관찰을 연구 질문으로 바꾸기

원 아이디어는 『기대의 감각』에 대한 사용자 메모에서 출발한다. 과거에는 사랑 이야기가 많았지만 최근 DAY6의 `HAPPY`, 황가람의 `나는 반딧불` 같은 곡에서 다른 정서를 읽었다는 내용이다. **이는 사용자가 정리한 저자의 관찰이며, 책의 해당 문장을 직접 대조한 인용은 아니다.** 두 곡의 라벨도 가사 검토 전에는 확정하지 않는다.

| 층위 | 질문 | 이 프로젝트가 제공할 수 있는 근거 |
|---|---|---|
| 관찰 | 차트에 오른 곡들의 주제·감정·메시지가 달라졌는가? | 정해진 표본과 분류 기준에 따른 구성비 |
| 비교 | 사랑 이야기가 줄었는가? 불안 표현과 위로 메시지는 각각 늘었는가? | 서로 다른 축의 변화와 동시 출현 비율 |
| 해석 | 왜 사람들이 이런 노래를 더 많이 찾는가? | 가능한 설명과 반례. 차트만으로 동기를 판별하지 못함 |
| 후속 검증 | 실제 청자의 심리 상태와 관련이 있는가? | 별도의 청자 조사·외부 지표가 필요한 확장 연구 |

**관측 대상은 ‘특정 차트에 나타난 인기곡의 표현’이다.** 청자의 현재 감정, 듣고 싶은 감정, 작사가의 표현, 유통·추천 구조가 섞인 결과이므로 이를 곧바로 국민의 심리 상태로 명명하지 않는다.

### 먼저 비교할 가설

- **H1 — 주제 변화:** 연애·관계 주제의 비중이 비교 시점에 따라 달라진다.
- **H2 — 정서 변화:** 불안·불확실성 표현의 비중이 달라진다. 슬픔·외로움과 별도로 센다.
- **H3 — 메시지 변화:** 위로·자기수용 메시지의 비중이 달라진다. 밝은 가사에도 나타날 수 있다.
- **경쟁 설명:** 소수 장기 흥행곡, 장르 구성, 리메이크, 차트 산정 방식이 변화를 설명할 수 있다.
- **가능한 결론:** 변화가 작거나 일관되지 않음 / 위로만 증가 / 특정 장르에서만 증가 / 자료 부족으로 판단 유보도 유효한 결과다.

‘사랑 → 불안’이라는 방향을 미리 정답으로 삼지 않는다. 사랑을 노래하면서 불안하고 위로하는 곡도 존재할 수 있도록 설계한다.

## 2. 분류 체계 — 무엇을, 어떤 마음으로, 어떻게 말하는가

다음은 **라벨링 규칙 v0.1 제안**이다. 기본 단위는 특정 가사 버전의 한 곡이며, 각 축은 복수 선택할 수 있다. 복수 선택 구성비의 합은 100%를 넘을 수 있다.

| 축 | 후보 라벨 | 판정 질문 |
|---|---|---|
| 주제 | 연애·관계 / 자기·정체성 / 삶·미래 / 사회·공동체 / 유희·소비 / 기타 | 무엇에 관한 노래인가? |
| 표현된 감정 | 불안 / 슬픔 / 외로움 / 분노 / 기쁨 / 희망 / 평온 | 화자가 어떤 감정을 드러내는가? |
| 메시지의 기능 | 위로·자기수용 / 연대 / 행동·극복 / 체념·회피 / 감정 서술 | 그 감정에 어떻게 응답하는가? |
| 서사 방향 | 고통 유지 / 고통에서 회복 / 낙관에서 좌절 / 혼합·불명확 | 앞부분과 결말의 태도가 달라지는가? |

### 판정 규칙

- **불안:** 미래의 위협·불확실성·걱정·통제 상실이 맥락상 드러날 때. 이별의 슬픔만으로 불안에 넣지 않는다.
- **위로·자기수용:** 자신이나 타인의 고통을 인정하거나, 존재의 가치·괜찮음·지지를 전달할 때. 단순히 밝거나 성공을 자랑하는 가사와 구별한다.
- **희망:** 긍정적 미래를 기대하는 표현. 타인을 다독이는 기능이 없어도 해당할 수 있다.
- **사랑:** 연애·애착·이별 관계가 주제인 경우. ‘사랑’이라는 단어가 있다는 이유만으로 판정하지 않는다.
- 부정문, 반어, 인용된 다른 화자의 말, 결말의 반전을 함께 읽는다. 키워드 출현은 판정의 단서다.
- 가사 미확보·일부 가사·언어 판독 불가·애매한 사례는 각각 기록한다. **‘없음’과 ‘모름’을 같은 0으로 처리하지 않는다.**
- 보컬이 없는 곡은 `not_applicable`로 구별한다. 번역본만 있는 경우 `translation_only` 표시를 남긴다.

예를 들어 **‘앞날이 두렵지만 서로를 지지하자’라는 가상의 내용**은 주제=삶·미래, 감정=불안+희망, 기능=위로+연대로 분류할 수 있다. 실제 노래 가사를 인용한 예시는 아니다.

### 기록 방식

각 라벨을 `present / absent / uncertain`으로 기록하고, 근거 위치·짧은 해석 메모·분류자·규칙 버전을 붙인다. 근거는 ‘2절의 미래 걱정, 마지막 후렴의 자기수용’ 같은 위치·요약으로 남기며 원문 복제를 기본값으로 삼지 않는다.

처음부터 0~100짜리 ‘불안 지수’를 만들지 않는다. 먼저 **있음/없음/판단 유보를 안정적으로 나눌 수 있는지** 검증한다. LLM의 자기보고 확신도는 정확도나 통계적 확률로 취급하지 않는다.

## 3. 첫 결과물과 사용 흐름

### 1차 사용자는 나 — 관찰에서 글감까지

1. 같은 차트의 두 시점을 선택하고, 자료 확보율과 산정 방식 변경 이력을 확인한다.
2. 주제·감정·메시지 비중을 각각 비교한다.
3. 변화에 기여한 곡, 반대 사례, 판정이 애매한 곡을 연다.
4. 장기 흥행곡·리메이크·특정 아티스트를 제외해도 해석이 유지되는지 확인한다.
5. 관찰 / 해석 후보 / 반례 / 한계를 구분한 Markdown 보고서를 내보낸다.
6. 사용자가 자기 판단을 덧붙여 글감이나 후속 질문으로 연결한다.

### MVP 산출물

- **요약 1쪽:** 질문, 대상 차트·연도, 분석 가능한 곡 수, 주요 차이, 해석 한계.
- **그림 3개:** 축별 구성비 비교 / 불안과 위로의 동시 출현 / 포함·제외 조건에 따른 결과 변화.
- **검토표:** 곡별 라벨, 근거 메모, 출처 링크, 미확보 사유, 분류 수정 이력.
- **재실행 묶음:** 입력 목록, 설정, 규칙·모델 버전, 결과 CSV와 실행 기록.

화면을 만든다면 상단에 기간·차트·확보율, 중단에 비교 그래프, 하단에 근거 곡 목록을 둔다. ‘대중의 불안 78점’ 같은 카드는 만들지 않는다. 화면 제작은 첫 보고서의 효용을 확인한 뒤 진행한다.

**가상 출력 문장:** “분석 가능한 곡에서 위로 메시지의 비중이 비교 시점 사이에 달라졌다. 자료 미확보 곡과 장르 구성의 영향은 남아 있다.” 실제 숫자는 분석 전 채우지 않는다.

### 가사·음원 이용 방침

기존 초안의 **‘분석 직후 원문을 삭제하면 무난하다’는 제안은 철회한다.** 삭제는 보관 범위를 줄이는 조치이며, 수집·복제·기계분석·외부 API 전송에 대한 허락을 대신하지 않는다. 소규모·비영리라는 이유만으로 이용 가능을 확정하지 않는다. 공정이용은 이용 목적·분량·시장 영향 등 여러 요소를 함께 판단한다. [국가법령정보센터 제35조의5](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=05&joNo=0035&lsiSeq=283335&urlMode=lsScJoRltInfoR)

확보 경로는 다음 순서로 조사한다.

1. 분석 용도가 허용된 차트 데이터·가사 데이터셋 또는 제공자 계약.
2. 권리자가 분석을 허락한 자료. 단, 이 표본이 차트 전체를 대표하는지는 별도 문제다.
3. 원문 기계처리가 어려우면 허용된 열람 범위에서 사람의 분류 메모를 만드는 경로 검토. 수동 입력도 자동으로 허용되는 것은 아니다.
4. 경로가 확보되지 않으면 직접 작성한 가상 자료로 입출력·집계만 검증하고, 실제 차트에 대한 결론은 보류한다.

소스별로 URL·확인일·대상 기간·허용 작업·보관 기간·외부 모델 전송 가능 여부·비용·허락 근거를 등록한다. 조건이 불명확한 소스는 `pending`으로 두고 운영 분석에 투입하지 않는다. 음향 분석도 분석 가능한 음원 확보가 선행 조건이다.

## 5. 한국 파일럿부터 시작하는 단계 설계

기존 ‘미국 30년 → 한국 → 일본’은 장기 확장안으로 남기고, **원 질문에 직접 닿는 한국 표본에서 분류 기준과 데이터 경로를 먼저 검증**한다.

### 파일럿 가안

- **대상:** 이용 조건과 과거 자료 확보가 확인된 한국의 단일 곡 차트.
- **비교 시점:** 완결된 연간 차트 2015년과 2025년, 각각 상위 30개 항목. 총 60개 차트 항목이며 중복곡은 한 번 분류한다.
- **선정 이유:** 10년 간격의 두 시점을 빠르게 대조하기 위한 방법 검증. 이 두 해만으로 장기 추세를 주장하지 않는다.
- **전제:** 동일 계열 차트라도 산정 방식 변화가 큰 경우 직접 비교하지 않고, 비교 가능한 기간으로 변경한 이유를 분석 전에 기록한다.
- **2026년:** 미완결 연도이므로 연간 차트와 섞지 않는다. 나중에 동일 주차 누계끼리 비교할 수 있다.
- **표본 고정:** 데이터·라벨 결과를 보고 유리한 연도를 다시 고르지 않는다. 가사 미확보곡을 임의의 다른 곡으로 교체하지 않는다.

| 단계 | 할 일 | 산출물·다음 단계 조건 |
|---|---|---|
| P0 데이터 가능성 | 차트·가사 경로, 허용 작업, 비용, 역사적 비교 가능성 확인 | 소스 등록표. 조건 미충족이면 실제 자료 분석 보류 |
| P1 분류 규칙 | 약 20곡으로 규칙 보정, 애매한 사례 기록 | 규칙 v1과 판정 사례집. 추세를 보며 규칙 수정하지 않음 |
| P2 파일럿 보고서 | 최대 60개 항목 수집·중복 정리·사람 검토·집계 | 구성비, 미확보율, 반례, 조건별 비교가 담긴 보고서 |
| P3 장기 시계열 | 조건이 비교 가능한 연속 연도, 연간 Top 100으로 확대 | 한두 해의 특이점인지, 지속 변화인지 구별 |
| P4 국가 비교 | 미국·일본에 현지 언어 검토 및 소스 실사 적용 | 국가 내부 변화부터 비교. 국가별 단일 심리 순위는 만들지 않음 |
| P5 반복 관측 | 주간 자료와 지속 실행, 필요시 대시보드 | 수집 실패·미검토 자료가 드러나는 정기 보고 |

P0~P2는 **약 4~6회 작업 세션**을 가정하되, 데이터 허락·비용 협의 대기 시간은 포함하지 않는다. 유료 계약·API 호출은 가격과 예상 처리량을 확인한 뒤 별도 결정한다.

P2의 성공은 ‘불안 증가를 발견함’이 아니라 **판정 근거를 추적할 수 있는 보고서가 나오고, 그 결과로 다음 탐구 질문을 고를 수 있음**이다. 미국 연구의 동일 방향 재현을 한국 분석의 통과 조건으로 삼지 않는다.

## 6. 집계 단위와 비교 지표

### 서로 다른 두 질문을 분리

| 단위 | 묻는 것 | 중복 처리 |
|---|---|---|
| 기간 내 고유곡 | 어떤 종류의 노래들이 인기곡 목록에 들어왔는가? | 같은 가사 버전은 기간 안에서 한 번 |
| 차트 항목 | 차트에 어떤 메시지가 얼마나 반복해서 등장했는가? | 주간 분석에서 장기 체류를 반복 반영 |

연간 차트 파일럿에서는 **각 연도 차트 항목의 동일 가중 비율**이 기본이다. 여러 연도에 나온 곡은 각 연도의 집계에는 들어가지만 분류 결과는 재사용한다. 향후 주간 자료에서는 두 단위를 함께 제시한다.

### 기본 계산

라벨별로 `present` 곡 수를 P, `absent`를 A, 자료 부족·판정 유보를 U로 두면:

- 판정 가능한 곡의 라벨 비율 = `P / (P + A)`
- 판정 확보율 = `(P + A) / (P + A + U)`
- 미확보·유보를 모두 미해당으로 볼 때의 하한 = `P / (P + A + U)`
- 모두 해당으로 볼 때의 상한 = `(P + U) / (P + A + U)`

이 상·하한은 **미확보 자료에 대한 극단 가정의 범위**이며 통계적 신뢰구간이 아니다. 가사 분석 비대상인 연주곡은 별도 집계하고 위 분모에서 제외하되, 전체 차트 항목 수와 제외 수를 함께 표시한다. 분모가 0이면 0%가 아니라 ‘계산 불가’다.

| 지표 | 목적 | 주의점 |
|---|---|---|
| 주제·감정·기능별 비율 | 무엇이 달라졌는지 분리해 보기 | 축별·라벨별 분모 표시 |
| 불안+위로 동시 출현 | 고통의 서술과 그 응답이 함께 있는지 보기 | 두 라벨 모두 판정 가능한 항목만 사용 |
| 연도 간 퍼센트포인트 차이 | 비중 변화의 크기 파악 | 상대 증가율과 혼동하지 않음 |
| 고유곡 수·미확보율 | 결과가 몇 곡에 의존하는지 보기 | 작은 표본의 변화 과장 방지 |
| 원곡 발매 후 경과 기간 | 신곡과 오래된 곡의 기여 비교 | 최초 발매일과 리메이크 발매일 분리 |

순위 가중치는 민감도 분석에서만 사용한다. 예를 들어 `w = 1 / log2(rank + 1)`로 가중한 비율과 동일 가중 비율을 비교하되, 이를 재생 점유율로 부르지 않는다. 순위 간 실제 소비량 차이는 알 수 없기 때문이다. 연말 순위에서 주간 체류 기간을 역산하지 않는다.

선정한 Top N 전체를 분석한 비율은 해당 목록의 기술통계다. 국민 전체에 대한 표본오차로 해석하지 않는다. 향후 불확실성을 추정한다면 반복 등장곡·주간 자기상관을 반영하고, 일반화 대상을 먼저 정한다.

## 7. 결과를 믿기 위한 검증

### 라벨 검증

1. **보정용과 평가용을 곡 단위로 분리한다.** 같은 곡이 두 연도에 있어도 양쪽에 나누지 않는다.
2. 가능하면 서로 다른 사람 2명이 연도·순위·가설 방향을 가린 상태에서 독립 판정한다. 사람이 1명이면 일정 간격 후 재판정하되, 이는 분류자 간 검증을 대체하지 않는다고 기록한다.
3. LLM을 쓰는 경우 먼저 사람 평가표를 만들고, 고정된 규칙·프롬프트로 평가용 곡을 분류한다. 입력은 허용된 텍스트만 사용하며 제목·기억으로 가사를 복원시키지 않는다.
4. 불안·위로·연애 라벨별 혼동표, precision·recall·F1, 유보율을 살핀다. 단순 전체 일치율만으로 드문 감정의 정확도를 주장하지 않는다.
5. **자동 분류 확대 기준 가안:** 핵심 라벨별 F1 0.80 이상이며 평가용 양성·음성 사례가 각각 10개 이상. 파일럿에서 사례 수가 부족하면 자동화 성능은 미검증으로 남기고 사람 검토를 유지한다. 이 수치는 공인 기준이 아닌 프로젝트 운영 가안이다.
6. 규칙을 수정하면 평가용 결과도 새 버전으로 다시 계산한다. 이미 본 평가셋으로 반복 튜닝했다면 새로운 미사용 평가셋을 마련한다.

LLM끼리의 일치나 사전 점수와의 일치는 보조 정보다. 노래의 의미에 대한 정답 보증으로 삼지 않는다.

### 비교 결과 검증

- **확보율:** 시점별 판정 확보율 80%를 초기 점검선으로 제안한다. 미달·시점 간 큰 격차가 있으면 비중 변화의 확정적 요약을 보류하고 누락 편향을 먼저 다룬다. 80%를 넘겨도 편향이 없다는 뜻은 아니다.
- **장르·아티스트 영향:** 특정 장르나 다수 진입 아티스트를 제외했을 때 방향이 바뀌는지 본다. 장르 미확인값도 보존한다.
- **곡 구성 영향:** 리메이크·시즌송·오래된 곡을 분리한다. 발매 후 2년 이상을 ‘오래된 곡’으로 두는 등 경계는 사전 설정하고 대안 경계도 확인한다.
- **가중치 영향:** 동일 가중과 순위 가중이 다르면 ‘일부 상위곡이 주도한 변화’ 가능성을 보고한다.
- **추가 축:** 음향 특징은 후속 보조 분석이다. 가사의 위로와 단조의 음악이 함께 있을 수 있으므로 축들이 같은 방향이어야 성공이라고 보지 않는다.

### 구조적으로 남는 한계

차트 산정 방식, 추천·플레이리스트, 팬덤, OST·방송·숏폼, 곡 공급과 마케팅, 청취자 구성 변화는 완전히 제거하기 어렵다. 제외 비교는 설명의 견고함을 점검하는 수단이며 인과 통제의 완료를 뜻하지 않는다.

가사에 표현된 감정과 청자가 느낀 감정은 다를 수 있다. 불안해서 위로를 찾는 경우와 즐거워서 같은 노래를 듣는 경우를 차트만으로 구별하지 못한다. 외부 설문과 함께 움직이더라도 집단 수준 상관을 개인의 심리 진단으로 바꾸지 않는다.

## 8. 데이터 구조와 처리 흐름

구현 시의 최소 구조 제안이다. 전체 가사·음원 보관 여부는 소스별 조건을 따르며, 분석 DB의 기본값은 메타데이터·라벨·이력이다.

| 데이터 | 주요 필드 | 설계 이유 |
|---|---|---|
| source_registry | source_id, URL, 확인일, 허용 작업, 보관 조건, 전송 조건, 비용, 상태 | 사용할 수 있는 데이터인지 추적 |
| chart_definitions | chart_id, market, metric, 집계 기간 규칙, methodology_version | 국가·소비 시장·차트 방식 구분 |
| chart_entries | chart_id, period_start/end, rank, recording_id, source_id | 차트 관측을 곡 자체와 분리 |
| recordings | recording_id, 제목, 아티스트, 원곡/버전, 발매일, lyric_version_id, 매칭 상태 | 동명곡·리메이크·번역판 혼동 방지 |
| lyric_versions | lyric_version_id, 언어, source_id, 확보 범위, 접근 참조, 보관 상태 | 같은 곡의 가사 수정·번역 구분 |
| annotations | lyric_version_id, axis, label, value, 판정자, 근거 위치, 규칙 버전 | 복수 라벨과 유보·수정 이력 보존 |
| runs | run_id, 입력 manifest, 설정, 코드/모델/프롬프트 버전, 시각, 출력 경로 | 과거 보고서를 재현·대조 |

고유키는 차트 항목의 경우 `(chart_id, period_start, period_end, rank)`를 기본으로 두고, 동일 순위 충돌은 덮어쓰기 대신 오류로 처리한다. 곡명 문자열만으로 자동 병합하지 않는다. 같은 가사인지 확인되지 않은 리메이크·번역·라이브 버전은 별도 상태로 남긴다.

```text
이용 조건 확인 → 입력 목록 확정 → 차트 항목 가져오기
→ 곡·버전 매칭 → 허용된 가사 확보 또는 사람 분류
→ 라벨 검증 → 집계·민감도 비교 → 보고서
                       ↘ 미확보·오류·유보 목록
```

### 기술 선택 가안

- 최초 입력은 검토 가능한 CSV, 분석은 Python·pandas, 저장은 SQLite를 가정한다.
- 첫 출력은 Markdown + CSV + 정적 그래프. 반복 비교 수요가 확인되면 Streamlit 등을 검토한다.
- 수집 어댑터와 분석기를 분리한다. 접근 조건이 다른 공급자를 교체해도 분류·집계 규칙은 유지한다.
- 감정 사전은 보조 기준선으로 두고, LLM·한국어 모델은 가사 표본 검증 후 선택한다. 일반 문장 감정 분류기의 성능을 가사에 그대로 가정하지 않는다.
- 보관 가능한 자료만 캐시한다. 보관이 제한되면 소스 버전·수집 시점·처리 설정·파생 결과를 남기고 재현 한계를 표시한다. 원문을 삭제했다면 ‘완전 재현 가능’이라고 주장하지 않는다.
- 실패한 수집은 미확보로 기록하고, 동일 입력을 재처리해도 차트 항목이 중복되지 않게 한다. 라벨 수정 시 영향받는 보고서를 식별한다.

[[Dev 폴더 Git 저장소 목록]]의 `BackTest_Finace`는 Python CLI 재사용 검토 후보다. 이번 작업에서는 해당 코드 구조·라이선스·적합성을 확인하지 않았으므로 재사용 가능을 확정하지 않는다.

## 9. 국가 비교와 ‘대중심리’로의 확장 조건

한·일·미는 **원 아이디어의 비교 대상**으로 유지한다. 세 시장을 선택한 개인적 이유는 사용자가 남길 항목이다.

- 국가 대신 **차트의 소비 시장**을 기록한다. 한국 차트의 영어 노래나 일본 차트의 한국 아티스트를 제외하지 않고 언어·아티스트 정보는 별도로 둔다.
- 서로 다른 종합 차트는 가중 요소가 다르므로 먼저 각 시장 내부의 변화량을 본다. 국가 간 불안 비율의 절대 서열화는 보류한다.
- 같은 플랫폼 차트를 쓰는 대안도 해당 플랫폼 이용자 구성의 차이를 없애지는 못한다.
- 원어 분류를 기본으로 하고, 번역은 보조로 쓴다. 언어별 판정 예시와 현지어 검토 없이 한국어 기준을 그대로 이식하지 않는다.
- 국가별 자료 확보율·불명확 판정 비율을 나란히 표시한다. 분류 성능 차이를 문화 차이로 해석하지 않는다.

실제 청취 동기까지 탐구한다면 별도 연구 질문을 세운다. 예를 들어 같은 곡을 듣는 이유가 공감·위로·흥·팬 활동 중 무엇인지, 듣기 전후 감정이 어떻게 다른지 조사하는 후속 설계다. 차트 분석의 MVP에는 포함하지 않는다.

## 10. 선행 연구에서 가져올 것과 가져오지 않을 것

논문은 방법 설계의 참고이며 이 프로젝트가 도달해야 할 정답이 아니다.

| 연구 | 확인 상태와 참고점 |
|---|---|
| DeWall·Pond·Campbell·Twenge (2011), *Tuning in to Psychological Change* | 저자 소속 대학의 원문 확인. 미국 인기 가사의 언어 지표를 시대별로 비교한 연구. 언어 지표와 사회 해석을 구별하며 읽을 것 |
| Parada-Cabaleiro 외 (2024), *Song lyrics have become simpler and more repetitive over the last five decades* | 논문 페이지 및 저자 기관 공개본 확인. 영어권 가사의 반복·복잡성·감정 등을 다룸. 장르·표본 설계 참고 |
| Napier & Shamir (2018), *Quantitative Sentiment Analysis of Lyrics in Popular Music* | DOI 후보 확보, 이번 조사에서 출판사 본문 접근 실패. 세부 분석법·결과는 원문 확인 전 보류 |
| Schellenberg & von Scheve (2012), *Emotional Cues in American Popular Music: Five Decades of the Top 40* | 음향적 정서 단서 연구의 후속 검토 후보. 가사 감정이나 청자의 불안 측정과 혼동하지 않을 것 |

참고: [DeWall 외 원문](https://people.uncw.edu/pondr/Publications_files/DeWalletalTuningIn.pdf), [Parada-Cabaleiro 외 논문](https://www.nature.com/articles/s41598-024-55742-x), [저자 기관 공개본](https://dbis.uibk.ac.at/sites/default/files/2025-08/parada-srep-2024.pdf), [Napier & Shamir DOI](https://doi.org/10.1525/jpms.2018.300411), [Schellenberg & von Scheve 저자 공개 페이지](https://www.researchgate.net/publication/230745983_Emotional_Cues_in_American_Popular_Music_Five_Decades_of_the_Top_40).

**기존 초안 정정:** “선행 연구와 같은 경향이 안 나오면 방법이 틀렸다”는 기준을 철회한다. 다른 언어·시기·표본의 결과가 다른 것은 오류의 증거가 아니다. 동일 자료·방법의 재현 실패라면 원인을 조사하고, 자료·방법을 바꿨다면 새로운 비교로 취급한다. 한국 비교나 최신 기간 자체가 연구상 새로운 기여라는 주장도 추가 문헌 검토 전에는 확정하지 않는다.

- [ ] CSV 입력과 보고서 출력 필드 확정.
- [ ] 소스가 확보되면 표본 목록과 비교 설정을 결과 열람 전에 고정.
- [ ] 파일럿 곡별 판정과 보고서 작성, 필요한 자동화 수준 재평가.

### 사용자 판단이 필요한 지점

| 결정 | LLM 가안 | 바뀌면 달라지는 것 |
|---|---|---|
| 첫 결과물 | 글쓰기와 탐구를 위한 근거 보고서 | 상시 대시보드가 우선이면 운영·갱신 설계 비중 증가 |
| 핵심 관심 | 불안의 증가와 위로의 증가를 별개로 비교 | 관심이 청취 동기라면 차트 밖의 조사 필요 |
| 첫 범위 | 한국 단일 차트, 두 연도 Top 30 | 미국 장기 연구 재현이 목적이면 별도 트랙으로 전환 |
| 데이터 비용 | 무료·허용 자료 경로부터 조사 | 유료 라이선스 예산에 따라 확보량·자동화 범위 변화 |
| 사람 검토 | 파일럿 전곡 검토 | 검토 시간·협력자 확보가 자동화 평가의 제약 |
| 한·일·미 선택 이유 | 원 아이디어를 유지하되 이유는 미기입 | 비교 질문과 차트 선정 기준이 달라짐 |

모든 결정을 마칠 때까지 준비를 멈출 필요는 없다. 분류 체계·가상 자료·보고서 형식은 먼저 다듬을 수 있다. 실제 차트 분석은 데이터 이용 조건과 비교 가능성이 충족되어야 한다.

**남길 질문:** 위로하는 노래가 늘었다면 사람들이 더 힘들어진 것일까, 힘듦을 말하는 방식이 달라진 것일까, 아니면 그런 노래가 더 잘 유통되게 된 것일까? 첫 보고서는 이 질문을 지우지 않고, 어떤 설명을 더 조사할지 좁히는 데 쓴다.
