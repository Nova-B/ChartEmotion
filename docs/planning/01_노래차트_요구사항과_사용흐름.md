# 노래차트 — 요구사항과 사용 흐름

상위 문서: [[00_노래차트_개발기획]]. 이 문서는 v0.1의 인수 가능한 동작과 v0.2 화면 방향을 정의한다.

## 1. 대표 사용 시나리오

“두 시점에 위로 메시지가 달라졌는지 보고 싶다.”

1. 실험 이름·차트·비교 기간·Top N·분류 규칙을 설정한다.
2. 두 기간의 차트 CSV를 불러오고 누락 순위·중복·출처 상태를 확인한다.
3. 같은 곡의 표기 차이를 매칭하고, 리메이크 등 다른 버전을 구별한다.
4. 곡별 분류표를 내보내 사람의 판정과 근거 메모를 작성한다.
5. 분류표를 다시 넣고 미검토·불일치·오래된 수정본을 점검한다.
6. 검토 상태를 포함한 분석 스냅샷을 생성한다.
7. 비교 결과와 민감도 분석, 미확보 목록을 읽고 보고서를 내보낸다.
8. 사용자가 ‘내 해석’과 다음 질문을 별도로 기록한다.

기간·표본·규칙을 바꾼 비교는 새 실험 개정으로 저장한다. 기존 결과를 덮어쓰지 않는다.

## 2. v0.1 필수 요구사항

| ID | 기능 | 완료 조건 |
|---|---|---|
| R01 | 실험 설정 | 차트·기간 2개·N·라벨셋·가중치·데이터 모드를 저장하고 누락값을 거부 |
| R02 | 출처 등록 | 입력 종류별로 이용 근거·허용 작업·확인일을 기록. 실제 자료의 미확인 상태를 차단 사유로 표시 |
| R03 | 차트 가져오기 | 행별 오류를 보여주며 검증 실패 시 해당 배치 전체를 반영하지 않음 |
| R04 | 곡·버전 매칭 | 후보와 확정 상태 구분. 문자열 유사도만으로 자동 확정하지 않음 |
| R05 | 검토표 왕복 | 라벨·근거·검토자를 CSV로 편집하고 revision 충돌을 감지 |
| R06 | 분류 상태 | 있음·없음·판단 유보, 미검토, 가사 미확보, 비대상을 구별 |
| R07 | 품질 점검 | 전체 항목·매칭 완료·가사 확보·라벨별 판정 확보·비대상 수를 각각 출력 |
| R08 | 기간 비교 | 동일 가중 비율·퍼센트포인트 차이·누락 가정 범위·동시 출현 계산 |
| R09 | 조건별 재비교 | 순위 가중, 아티스트 제외, 오래된 곡 제외를 기준 결과와 병렬 표시 |
| R10 | 보고서 | Markdown·CSV·PNG·manifest를 하나의 run 폴더에 생성 |
| R11 | 이력 | 입력·판정 개정·규칙·코드 버전을 추적하고 과거 run의 숫자를 유지 |
| R12 | 가상 자료 시연 | 네트워크·키 없이 예제 전 과정을 실행하고 모든 결과에 가상 표시 |

R09에서 발매일·아티스트가 없으면 해당 조건의 ‘정보 미확보’를 표시한다. 미확인 곡을 조용히 제외하지 않으며, 제외 실험의 분모·제외 목록·미확인 처리 방침을 함께 기록한다.

## 3. 라벨링 작업 규칙

라벨 정의는 [[노래차트_대중심리분석_설계#2. 분류 체계 — 무엇을, 어떤 마음으로, 어떻게 말하는가]]를 따른다.

- 주제·감정·메시지는 복수 라벨 가능. 각 라벨을 독립적으로 판정한다.
- 서사 방향은 보조 메모 필드로 시작하며, v0.1 필수 집계에서 제외한다. 서사 분류를 확정할 때 단일/복수 선택 규칙을 별도로 정한다.
- 체크하지 않은 칸을 자동 ‘없음’으로 바꾸지 않는다. **미입력은 미검토**다.
- 사람의 채택 판정만 기본 집계에 쓴다. 모델 제안과 독립 검토자 판정은 별도 보존한다.
- 독립 판정이 충돌하면 조정 판정을 남기고, 미조정은 판단 유보로 집계한다.
- 검토할 텍스트가 없으면 곡 제목이나 모델의 기억으로 채우지 않는다.
- 불안·위로에 ‘있음’을 붙이면 근거 위치와 해석 메모를 필수로 남긴다.
- 일부 가사와 번역본만 있는 곡은 파일럿의 기본 집계에서 미판정 U로 처리한다. 포함하는 보조 실험은 별도 설정한다.

## 4. 오류와 빈 상태

| 상황 | 표시·복구 |
|---|---|
| CSV 열 누락·순위 형식 오류 | 파일명·행·열·오류 코드를 출력, DB 반영 없음 |
| 동일 배치 재입력 | 이미 반영됨을 안내하고 새 행을 만들지 않음 |
| 같은 순위에 다른 곡 | 충돌로 중단. 정정 배치로 새 스냅샷 작성 |
| 곡 매칭 미확정 | 검토 대기열에 남기고 라벨 집계에서는 U |
| 라벨셋 버전 불일치 | 섞어 집계하지 않고 해당 버전 재검토 안내 |
| 판정 가능한 항목 없음 | 0% 대신 ‘계산 불가’와 부족 원인 표시 |
| 한 기간의 차트 항목 자체가 누락 | 품질 보고서만 생성, 정상 비교 보고서 생성 차단 |
| 미확보가 많음 | 분모·범위를 표시하고 ‘해석 보류’ 상태 출력 |
| 보고서 출력 실패 | 실패 상태·원인을 남기고 완성 폴더로 승격하지 않음 |
| 이전 분류표로 수정 시도 | 최신 revision과 비교해 충돌 목록 제공, 자동 덮어쓰기 없음 |

## 5. v0.2 화면 기획

화면 구현은 v0.1 보고서 사용 후 착수한다. 최초 화면은 파일·실험을 고르는 로컬 작업 공간이며 로그인은 없다.

| 화면 | 주요 내용 | 대표 동작 |
|---|---|---|
| 실험 목록 | 차트·기간·진행률·최근 결과·가상/실제 | 생성, 복제하여 새 비교 |
| 자료 점검 | 순위 누락, 중복, 매칭 후보, 출처 상태 | 오류 확인, 버전 확정 |
| 곡 검토 | 곡 정보, 출처 링크, 근거 메모, 라벨, 이전 판정 | 저장 후 다음 곡, 유보 |
| 비교 결과 | 확보율, 축별 비중, 동시 출현, 조건별 변화 | 그래프 항목에서 기여곡 열기 |
| 보고서 | 관찰·해석 자리·반례·한계·실행 정보 | 결과 묶음 저장 |

검토 화면은 가능하면 연도·순위를 접어 판정 편향을 줄인다. 저장 전 미입력 라벨 수를 보여주며, ‘모두 없음’은 명시적인 동작으로만 제공한다. 모든 화면에서 모름을 회색 0점처럼 표시하지 않는다.

## 6. 사용자가 읽을 보고서 구성

1. 질문과 표본 정의.
2. 자료 상태: 전체·제외·미확보·판정 수.
3. 축별 변화: 숫자·분모·단위.
4. 변화에 기여한 곡과 반례.
5. 조건을 바꾸었을 때의 결과.
6. 해석 후보와 대안 설명.
7. 사용자 해석란과 다음 질문.
8. 입력·규칙·실행 버전 및 재현 한계.

LLM 해석을 붙이는 후속 기능은 수치와 원자료의 출처를 유지해야 한다. 사용자 해석란을 자동 생성하지 않는다.
