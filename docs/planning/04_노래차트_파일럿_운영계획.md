# 노래차트 — 파일럿 운영 계획

상위 문서: [[00_노래차트_개발기획]]. 프로그램 동작 검증과 실제 자료 분석을 구별하기 위한 실행 기록 양식이다. **표의 ‘미확인’은 아직 확보하거나 실행하지 않았다는 뜻이다.**

## 1. 첫 실제 실험 가안

| 항목 | 값·상태 |
|---|---|
| 질문 | 인기곡의 연애 주제·불안 감정·위로 메시지가 두 시점에서 다른가? |
| 시장 | 한국 |
| 차트 | 미선정. 동일 계열·집계 방식 비교 가능성이 우선 |
| 표시 연도 | 2015 / 2025 가안 |
| 실제 집계 시작·종료 | 공급자 정의 확인 후 입력 |
| 표본 | 시점별 Top 30, 총 60개 차트 항목 |
| 분석 단위 | 차트 항목, 동일 가중 |
| 핵심 라벨 | theme.romance / emotion.anxiety / function.comfort |
| 보조 분석 | 불안+위로 동시 출현, 순위 가중, 아티스트·오래된 곡 제외 |
| 데이터 확보·비용 | 미확인 |
| 이용 조건 | 원 설계의 조사 참고, 실제 사용 범위 확인 전 대기 |
| 현재 상태 | 설계 가안. 수집·분류·분석 미실행 |

## 2. 소스 등록 양식

차트와 가사는 **별도 소스**로 등록한다. 소스가 공개되어 있다는 사실만으로 실제 분석 가능 상태로 바꾸지 않는다. 원 설계의 [[노래차트_대중심리분석_설계#4. 데이터 확보 — 확인한 사실과 남은 관문]]에 공식 출처가 정리되어 있다.

| 필드 | 기입 내용 |
|---|---|
| source_id / 자료 종류 | 식별자 / 차트·가사·메타데이터 |
| 제공자 / URL | 실제 제공 주체와 원문 위치 |
| 확인일 / 확인자 | 이용 조건을 확인한 날짜와 주체 |
| 대상 기간·언어·확보량 | 표본을 얼마나 포함하는지 |
| 가져오기·분석·보관 | 작업별 가능·불가·미확인 |
| 외부 모델 전송 | 가능·불가·미확인, 공급자 조건 |
| 파생 결과 공개 | 집계·곡명·근거 메모 공개 조건 |
| 근거 | 문서 URL·계약 범위·허락 기록 |
| 비용 | 초기 비용·단위 비용·상한 |
| 만료·재확인 조건 | 이용 기간·정책 변경·범위 확대 |
| 처리 상태 | pending / permitted / restricted |

`permitted`도 모든 작업의 포괄 허락이 아니다. 실제 작업이 허용 목록에 들어가는지 실행 시 확인한다. 가상 자료는 `synthetic` 출처로 별도 표시한다.

## 3. 실험 순서와 기록

1. **자료 경로 점검:** 차트 목록·가사·매칭 메타데이터의 가용 범위와 사용 조건 확인.
2. **비교 가능성 검토:** 산정 방식 변경·집계 기간·상위권 길이·곡/음반 차트 구분 기록.
3. **표본 고정:** 곡별 라벨을 보기 전에 차트·기간·N·제외 기준을 manifest로 저장.
4. **규칙 보정:** 약 20개 고유 가사 버전으로 어려운 사례를 모아 라벨 규칙 수정.
5. **규칙 동결:** labelset_version을 붙이고, 보정에 쓴 곡과 평가곡을 분리.
6. **파일럿 전곡 검토:** 가용 곡을 판정하고, 미확보는 교체 없이 이유 기록.
7. **분석·조건별 비교:** 두 기간의 확보율과 기여곡을 함께 확인.
8. **해석 기록:** 결과가 가설을 지지·반박·판단 유보 중 어디에 해당하는지 작성.

같은 가사 버전이 두 기간에 나오면 동일한 평가 분할에 배치한다. 같은 원작의 매우 유사한 버전도 모델 평가에서는 같은 그룹으로 묶는 방안을 검토한다. 모델 튜닝용 자료와 사람 평가용 자료를 섞지 않는다.

## 4. 사람 검토 운영

단일 사용자가 전곡 검토하는 방식으로 시작할 수 있다. 이를 두 사람의 독립 검증과 동일하게 부르지 않는다.

- 두 번째 검토자가 가능하면 서로의 판정을 보기 전에 독립 분류한다.
- 불일치 이유와 조정 판정을 남긴다. 일부 합의가 안 되면 uncertain을 유지한다.
- 모델 자동화는 후속 기능이다. 평가셋이 작아 라벨별 양성·음성 10개를 확보하지 못하면 확대 기준의 검증을 보류한다.
- 선행 설계의 F1 0.80 및 확보율 80%는 초기 운영 가안이며 공인 연구 기준이 아니다.
- 확보율은 가사 획득률과 라벨 판정 가능률을 나누어 본다. 가사를 구했어도 해석이 불분명할 수 있다.

## 5. 시간·비용 기록

| 항목 | 추정 방법 | 초기 상태 |
|---|---|---|
| 자료 취득 | 공급자 비용 + 기간별 확보·정리 시간 | 미확인 |
| 사람 검토 | 고유곡 수 × 시범 10곡의 평균 검토 시간 | 미측정 |
| 재검토 | 불일치곡 수 × 평균 조정 시간 | 미측정 |
| 모델 비용 | 실제 토큰량 × 해당 요율 + 재시도량 | 모델 미선정 |
| 반복 실행 | 신규곡 수 + 수정곡 수 기준 | 파일럿 후 산정 |

예를 들어 60항목을 그대로 60회 분류하지 않고, 매칭된 고유 가사 버전 수로 검토량을 계산한다. 이 표를 채우기 전 일정·비용을 확정 금액으로 제시하지 않는다.

## 6. 결과 판정 양식

실행 후 아래 항목을 채운다. 현재는 빈 양식이다.

- run_id:
- 분석한 차트·집계 기간:
- 전체 / 비대상 / 미확보 / 판정 가능 항목:
- 관측된 차이와 퍼센트포인트:
- 누락 가정 범위를 고려한 해석:
- 가중치·곡 제외 후 유지되는 결과:
- 결과를 주도한 곡과 반례:
- 분류·자료·차트 방식의 한계:
- 사용자의 해석:
- 다음 선택: 자료 보완 / 규칙 수정 / 연속 연도 확대 / 질문 변경 / 보류

숫자의 방향이 예상과 달라도 데이터를 바꾸어 가설을 살리지 않는다. 후속 지표를 탐색하면 탐색 분석이라고 표시하고, 새 확인 실험은 별도 표본·설정으로 구성한다.
